What you can do

何ができるの？

基本はシンプルです。文章を書けば、その文章を音声として読み上げます。端末や使う場所に合わせて、動かし方だけを選べます。

01

文章を、その場で読み上げ

入力した文章を音声へ変換。会話中に打ち込んだ文章を声として届けたいときにも使えます。

02

スマホ・タブレットでも

専用アプリを入れるのではなく、ブラウザから同じ画面を利用できます。PCの前にいないときも使えます。

03

準備後はオフラインでも

音声モデルを端末へ準備しておけば、通信できない場所でも端末側で音声を生成できます。

04

重い処理はPCへ

モバイル側はクライアントとして使い、音声合成だけを別のPCへ任せるサーバーモードも用意しています。

ブラウザを開けば、そこが読み上げ画面

typed-voiceは「モデルをどう動かすか」を先に考えるための画面ではありません。はじめて開いたときの案内に沿って準備したら、普段は文章を入力して読み上げるだけです。

同じ画面の中に会話、読み上げ履歴、設定をまとめています。PC用とモバイル用で別々の操作を覚えるのではなく、端末が変わっても同じ使い方を目指しています。

Offline mode

端末だけで使う、オフラインモード

最初に音声モデルを準備すると、対応するブラウザでは必要なデータを端末へ保存します。準備が終わったあとは、同じ大容量モデルを毎回取り直す必要はありません。

通信できない場面では、保存済みのモデルを使って端末の中で音声を生成します。ネットワーク越しに自宅PCへ接続したくないときも、このモードだけで使えます。

こんなときに外出先、回線が不安定な場所、PCを起動していないとき。

Server mode

スマホから、PCの力を借りる。

モバイル端末で画面を操作しながら、実際の音声合成は別のPCへ任せることもできます。端末側へ大きな負荷を掛けたくないときのためのクライアントモードです。

1

PCでサーバーを起動

typed-voice-serverを起動すると、モバイルを接続するための情報が用意されます。

2

QRコードで接続

スマートフォンやタブレットならQRコードを読み取るだけ。ファイルを渡せる環境では接続鍵ファイルも利用できます。

3

いつもの画面から読み上げ

入力はモバイル側。音声生成は接続先PC側。生成された音声だけを受け取って再生します。

接続先を手で入力しなくていい

サーバーが用意したQRコード、または接続鍵ファイルに必要な接続情報をまとめています。モバイル側で長いURLや鍵を打ち込む必要はありません。

通常起動ではRemote接続だけを外部へ公開し、管理画面やWorker参加口はローカルに残す構成です。自分のPCを自分のモバイルから使うだけなら、公開範囲を増やさず利用できます。

typed-voice-server

もっと使うなら、専用サーバー。

typed-voice-serverは、1台のPCだけでなく、参加したTrusted Workerへ音声合成を割り振れるサーバープロジェクトです。ブラウザをWorkerとして参加させ、必要に応じて処理役を増やせます。

ブラウザをWorkerに

Worker用URLを信頼できる参加者へ渡すと、そのブラウザを音声合成Workerとして参加させられます。

Workerは動的に増減

開いているWorkerに処理を割り振り、切断したWorkerの処理は条件内で別Workerへ再割り当てします。

管理画面からモデル選択

利用するモデルをサーバー側で選択し、参加中のWorkerへ同じ設定を配布します。

For Windows

普段の起動はServer.cmdから

Windows向け配布では、必要な環境を準備したあとは展開先のServer.cmdから起動できます。Remote用のQuick Tunnelも通常起動時に用意されます。
